# Experience — онлайн-версия трансформационной игры

Браузерная игра-путь к осознанию. Работает без сервера: обычный сайт из HTML, CSS и JavaScript, все данные игрока хранятся в его браузере.

## Как играть

1. **Запрос.** Игра спрашивает, чего ты хочешь, помогает сформулировать желание в созидательном ключе (получить что-то, а не избавиться от чего-то) и задаёт уточняющие вопросы.
2. **Вход.** Вытаскивай карты пути, пока не откроется карта стихии. Остальные карты уходят в резерв. После трёх неудачных попыток игра предлагает подумать над запросом глубже.
3. **Путь.** Каждый ход можно взять одну новую карту и нужно пойти одной картой из резерва. Карта ложится на следующую клетку поля; стрелка на ней задаёт направление для следующей. Карты Препятствия, Ресурса и Подсказки открывают карту из своей колоды — игрок записывает, что он видит. Карта Осознание — точка, где нужно записать, что уже понято.
4. **Финал.** Когда дорожка приходит к Оку в центре поля, игрок получает напутствие, записывает главное осознание и получает маршрутный лист со всеми картами и записями. Маршрут можно распечатать, сохранить в PDF или скачать текстом.
5. **Дневник.** Все игры сохраняются в дневнике в браузере; незаконченную игру можно продолжить в другой день. Дневник можно скачать как резервную копию и загрузить на другом устройстве.

## Структура

- `index.html` — страница игры
- `css/style.css` — оформление
- `js/geometry.js` — геометрия поля (шестиугольник, 96 треугольных клеток)
- `js/data.js` — карты, колоды, тексты вопросов и подсказок
- `js/app.js` — логика игры и интерфейс
- `assets/` — поле, карты пути, колоды препятствий, ресурсов и подсказок (сжатые для веба)
- `.nojekyll` — чтобы GitHub Pages публиковал файлы как есть

## Запуск локально

Откройте `index.html` в браузере или запустите любой статический сервер в папке проекта, например:

```
python3 -m http.server 8080
```

и откройте http://localhost:8080/

## Публикация на GitHub Pages

В настройках репозитория: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, выбрать ветку с игрой и папку `/ (root)`, нажать **Save**. Через одну-две минуты игра доступна по адресу `https://<логин>.github.io/game-elena/`.
